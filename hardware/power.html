Power Section

Power entry, regulation, protection, board on/off control, and 3.3 V / 5 V status indicators.

Open pinout reference Open all examples

Configuration Location

  • Power selection switch and input connectors are found in this Power hardware section.
  • SW1 is the main board power switch and can turn all board power on or off.
  • Board power input can be 5 V from any USB connector, or up to 36 V from the power jack, power socket, or X30 battery socket.
  • Before every example, power the board and confirm the 3V3 and 5V indicators are on.
Set the switches for the selected example before running the firmware. If the same MCU pin is shared by two board functions, only one route should be active.

How This Section Is Used

  • Use this section first for every lab because all other blocks depend on stable 3.3 V and 5 V rails.
  • Set SW1 to ON to power the board, or OFF to shut down the full board power path.
  • Use 5 V when powering from USB. For the power jack, power socket, or X30 battery socket, keep the external supply at or below 36 V and share ground with external instruments.

Basic GPIO

LED Blinking

Flashes LED1..LED4 on PB6, PB7, PC10, and PC11.

Source: 7segments\LedBlinking.c

Configuration location: DIP in Module Card

Download ZIP

Pre-configuration

  1. Set the module DIP bank to the neutral I2C side so it does not load the LED/GPIO routes.
  2. Power the board and confirm 3V3/5V LEDs are on.

Run steps

  1. Build and program LedBlinking.c.
  2. Observe LED1..LED4 flashing in sequence.

Hardware section

GPIO, Inputs, Buttons, and LEDs

Copy-ready snippet: LedBlinking.c

7segments\LedBlinking.c

void main() {

  // Configure LED pins as output
  GPIO_Digital_Output(&GPIOC_BASE, _GPIO_PINMASK_10 | _GPIO_PINMASK_11);
  GPIO_Digital_Output(&GPIOB_BASE, _GPIO_PINMASK_6  | _GPIO_PINMASK_7);

  // Turn all LEDs OFF initially
  GPIOC_ODR &= ~(_GPIO_PINMASK_10 | _GPIO_PINMASK_11);
  GPIOB_ODR &= ~(_GPIO_PINMASK_6  | _GPIO_PINMASK_7);

  while(1) {

    // LED4 (PC11)
    GPIOC_ODR |= _GPIO_PINMASK_11;
    Delay_ms(1000);
    GPIOC_ODR &= ~_GPIO_PINMASK_11;

    // LED3 (PC10)
    GPIOC_ODR |= _GPIO_PINMASK_10;
    Delay_ms(1000);
    GPIOC_ODR &= ~_GPIO_PINMASK_10;

    // LED2 (PB7)
    GPIOB_ODR |= _GPIO_PINMASK_7;
    Delay_ms(1000);
    GPIOB_ODR &= ~_GPIO_PINMASK_7;

    // LED1 (PB6)
    GPIOB_ODR |= _GPIO_PINMASK_6;
    Delay_ms(1000);
    GPIOB_ODR &= ~_GPIO_PINMASK_6;
  }
}
Advanced Low Power

Sleep Wake by EXTI0

Enters sleep mode and wakes on PA0 EXTI0, pulsing PB6.

Source: 7segments\STM_EXTI0.c

Configuration location: no special switch setting listed for this example.

Download ZIP

Pre-configuration

  1. Connect a rising-edge wake source to PA0.
  2. Keep PB6 LED route available.

Run steps

  1. Build and program STM_EXTI0.c.
  2. The MCU sleeps until PA0 rises, then PB6 turns on briefly.

Hardware section

Programming, Reset, and Wake

Copy-ready snippet: STM_EXTI0.c

7segments\STM_EXTI0.c

void main() {
    RCC_AHB1ENR.B0 = 1; // GPIOA
    RCC_AHB1ENR.B1 = 1; // GPIOB
    SYSCFGEN_bit = 1;   // SYSCFG

    GPIO_Digital_Input(&GPIOA_BASE, _GPIO_PINMASK_0);    // PA0 input
    GPIO_Digital_Output(&GPIOB_BASE, _GPIO_PINMASK_6);   // PB6 output

    SYSCFG_EXTICR1 &= 0xFFF0;  // EXTI0 -> PA0
    EXTI_IMR.B0 = 1;
    EXTI_RTSR.B0 = 1;          // rising edge
    EXTI_FTSR.B0 = 0;

    NVIC_IntEnable(IVT_INT_EXTI0);

    while (1) {
        LED = 0;
        enter_sleep();         // wakes on PA0 interrupt
        LED = 1;
        Delay_ms(200);
    }
}

Standby Wake-Up

Enters standby mode after startup and wakes using the wake-up button route.

Source: 7segments\STM_Standby.c

Configuration location: SW5 in ESP32 / USB

Pre-configuration

  1. Set SW5 to Wake_UP side.
  2. Use the wake-up button/input to resume from standby.

  1. Build and program STM_Standby.c.
  2. After the startup LED pulse, the MCU enters standby; press wake-up to restart.

Programming, Reset, and Wake

Copy-ready snippet: STM_Standby.c

7segments\STM_Standby.c

void main() {
    RCC_AHB1ENR.B1 = 1;                               // GPIOB clock
    GPIO_Digital_Output(&GPIOB_BASE, _GPIO_PINMASK_6); // PB6 output
    LED = 0;

    RCC_APB1ENR.B28 = 1;                              // PWR clock

    if (PWR_CSR.B1) {                                 // SBF: woke from Standby
        PWR_CR.B3 = 1;                                // clear standby flag
        LED = 1;
        Delay_ms(500);
        LED = 0;
    }

    Delay_ms(1000);                                   // demo delay
    enter_standby();

    while (1);
}
