Firmware quick guide

Write, Compile, and Upload the First Firmware

Install a firmware IDE and STM32CubeProgrammer, create a project for the STM32F446RE, compile a HEX file, download it over USB, then return the board to normal run mode.

Required software

Download and Install

You can write and compile firmware with any STM32-capable IDE. This guide uses mikroC PRO for ARM, but Keil or STM32CubeIDE can also be used. STM32CubeProgrammer is used to upload the compiled HEX file to the board.

Firmware IDE

mikroC PRO for ARM

Used in this guide to create a standard project, select STM32F446RE, write C code, and compile the HEX file.

Alternative IDEs are acceptable if they can target the STM32F446RE and generate a firmware image.

Download mikroC PRO for ARM
Firmware uploader

STM32CubeProgrammer

Used to open the generated HEX file, connect to the board over USB, and download the firmware.

Install this before starting the upload steps. The board must already be prepared using the Quick Start hardware guide.

Download STM32CubeProgrammer

Before uploading: complete the hardware preparation guide first so the board is in bootloader mode and ready to accept firmware.

Starter code

First Example: LED Blinking

Copy this code into the mikroC editor for the first test firmware. It flashes LED4, LED3, LED2, and LED1 using PC11, PC10, PB7, and PB6.

/*
   ------------------------------------------------------------
   STM32F446RE - LED Test
   mikroC PRO for ARM
   ------------------------------------------------------------

   LED outputs:
     LED4 -> PC11
     LED3 -> PC10
     LED2 -> PB7
     LED1 -> PB6

   Operation:
     LED Flashing

   Assumption:
     - LED ON = logic HIGH
*/
void main() {

  // Configure LED pins as output
  GPIO_Digital_Output(&GPIOC_BASE, _GPIO_PINMASK_10 | _GPIO_PINMASK_11);
  GPIO_Digital_Output(&GPIOB_BASE, _GPIO_PINMASK_6  | _GPIO_PINMASK_7);

  // Turn all LEDs OFF initially
  GPIOC_ODR &= ~(_GPIO_PINMASK_10 | _GPIO_PINMASK_11);
  GPIOB_ODR &= ~(_GPIO_PINMASK_6  | _GPIO_PINMASK_7);

  while(1) {

    // LED4 (PC11)
    GPIOC_ODR |= _GPIO_PINMASK_11;
    Delay_ms(1000);
    GPIOC_ODR &= ~_GPIO_PINMASK_11;

    // LED3 (PC10)
    GPIOC_ODR |= _GPIO_PINMASK_10;
    Delay_ms(1000);
    GPIOC_ODR &= ~_GPIO_PINMASK_10;

    // LED2 (PB7)
    GPIOB_ODR |= _GPIO_PINMASK_7;
    Delay_ms(1000);
    GPIOB_ODR &= ~_GPIO_PINMASK_7;

    // LED1 (PB6)
    GPIOB_ODR |= _GPIO_PINMASK_6;
    Delay_ms(1000);
    GPIOB_ODR &= ~_GPIO_PINMASK_6;
  }
}
